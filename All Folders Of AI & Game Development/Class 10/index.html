PART 1 · MATH OPERATORS

Arithmetic Operators

These work exactly like a calculator — apply them to number variables

OpNameExampleResult
+Addition10 + 313
-Subtraction10 - 37
*Multiplication10 * 330
/Division10 / 42.5
%Modulo (remainder)10 % 31
^Power / Exponent2 ^ 8256
What is Modulo %?
It gives the remainder after division. 10 % 3 = 1 because 10 ÷ 3 = 3 remainder 1. In games: used to check if a number is even/odd, or if every 5th event should trigger something.
LUA — Math operators with variables local score = 100
local bonus = 25
local lives = 3

-- Addition
print(score + bonus) -- 125

-- Subtraction
print(score - 30) -- 70

-- Multiplication
print(bonus * lives) -- 75

-- Power
print(2 ^ 10) -- 1024

-- Modulo — is score even?
print(score % 2) -- 0 = even!
Output
125
70
75
1024
0
PART 1 · EXPRESSIONS

Expressions — Using Operators Together

An expression is any combination of variables and operators that produces a value

LUA — Expressions in a game context local baseScore = 50
local multiplier = 3
local penalty = 10
local lives = 5

-- Calculate final score
local finalScore = (baseScore * multiplier) - penalty
print("Final Score: " .. finalScore) -- 140

-- Update lives
lives = lives - 1
print("Lives left: " .. lives) -- 4

-- Increase score by 20%
finalScore = finalScore * 1.2
print("Boosted Score: " .. finalScore) -- 168
Output
Final Score: 140
Lives left: 4
Boosted Score: 168.0
Order of Operations
Lua follows BODMAS / PEMDAS:
^ first → * / → + -
Use ( ) to control the order explicitly.
Real Game Use
Every game uses expressions: damage = attack * weapon_power, XP needed = level ^ 2 * 100, speed = baseSpeed + boost
PART 1 · COMPARISON OPERATORS

Comparison Operators

These compare two values and always return true or false — they feed directly into if/then

OpMeaningExampleResult
==Equal to5 == 5true
~=NOT equal to5 ~= 3true
>Greater than10 > 3true
<Less than3 < 10true
>=Greater or equal5 >= 5true
<=Less or equal4 <= 5true
⚠️ = vs ==
= assigns a value to a variable.
== compares two values.
This is the most common beginner mistake!
LUA — Comparison operators local score = 80
local target = 100
local lives = 3

print(score == target) -- false (80 is not 100)
print(score ~= target) -- true (80 is not equal to 100)
print(score > 50) -- true (80 is greater than 50)
print(score < target) -- true (80 is less than 100)
print(lives >= 1) -- true (player still alive)
print(lives == 0) -- false (not game over yet)

-- Store the result in a variable
local isWinning = score > 50
print("Is winning: " .. tostring(isWinning)) -- true
PART 1 · LOGICAL OPERATORS

Logical Operators — and · or · not

Combine multiple conditions into one — essential for complex game logic

🔗
AND
Both must be true
Returns true only if condition A and condition B are both true
lives > 0 and score > 50
🔀
OR
At least one true
Returns true if condition A or condition B (or both) are true
hasKey or hasCode
🔄
NOT
Flips the value
Turns true into false and false into true
not isGameOver
Output
Can enter: false
Has access: true
Game running: true
LUA — Logical operators local lives = 3
local score = 80
local hasKey = false
local hasCode = true
local isGameOver = false

-- AND: both must be true
local canEnter = hasKey and hasCode
print("Can enter: " .. tostring(canEnter)) -- false

-- OR: at least one must be true
local hasAccess = hasKey or hasCode
print("Has access: " .. tostring(hasAccess)) -- true

-- NOT: flip the value
local isRunning = not isGameOver
print("Game running: " .. tostring(isRunning)) -- true
PART 2 · STRING METHODS

String Methods — Working With Text

Lua has built-in functions to inspect and transform string variables. These are called with string.methodName()

📏
Method 1
string.len()
Returns the number of characters in a string — including spaces
string.len("Hello") → 5
🔠
Method 2
string.upper()
Converts all letters in the string to UPPERCASE
string.upper("hello") → "HELLO"
🔡
Method 3
string.lower()
Converts all letters in the string to lowercase
string.lower("HELLO") → "hello"
✂️
Method 4
string.sub()
Extracts a piece of a string from position start to end
string.sub("Hello", 1, 3) → "Hel"
🔁
Method 5
string.rep()
Repeats a string a given number of times
string.rep("Ha", 3) → "HaHaHa"
🔃
Method 6
string.reverse()
Reverses the characters of a string completely
string.reverse("Hello") → "olleH"
Shortcut syntax: myString:upper() — same as string.upper(myString) — both work in Roblox
PART 2 · METHODS 1–3 · DEEP DIVE

len() · upper() · lower()

The most commonly used string methods — great for username validation and display text

METHOD 1
string.len( str )
Counts every character — letters, numbers, spaces, symbols. Returns a number.
local name = "Roblox"
local city = "Islamabad"

print(string.len(name))
print(string.len(city))

-- Short syntax:
print(name:len())
Output
6
9
6
METHOD 2
string.upper( str )
Converts all letters to capitals. Numbers and symbols are not changed.
local playerName = "ahmed ali"

local loud = string.upper(playerName)
print(loud)

-- Short syntax:
print(playerName:upper())

-- Use case: show winner name big
print("WINNER: " .. playerName:upper())
Output
AHMED ALI
AHMED ALI
WINNER: AHMED ALI
METHOD 3
string.lower( str )
Converts all letters to lowercase. Useful for normalizing input before comparing.
local input = "ROBLOX"
local password = "SECRET123"

print(string.lower(input))

-- Short syntax:
print(password:lower())

-- Compare regardless of case
local match = (input:lower() == "roblox")
print(tostring(match))
Output
roblox
secret123
true
PART 2 · METHODS 4–6 · DEEP DIVE

sub() · rep() · reverse()

Cut, repeat, and flip strings — powerful tools for building game text and UI

METHOD 4
string.sub( str, i, j )
Extracts characters from position i to position j. Positions start at 1. Use negative numbers to count from the end.
local word = "Roblox Studio"

-- First 6 characters
print(string.sub(word, 1, 6))

-- From position 8 to end
print(string.sub(word, 8))

-- Last 6 characters
print(string.sub(word, -6))
Output
Roblox
Studio
Studio
METHOD 5
string.rep( str, n )
Repeats the string n times. Useful for drawing dividers, patterns, loading bars.
-- Repeat a laugh
print(string.rep("Ha", 5))

-- Draw a divider line
print(string.rep("=", 20))

-- Simple health bar (5 lives)
local hp = 3
print(string.rep("❤️", hp))
Output
HaHaHaHaHa
====================
❤️❤️❤️
METHOD 6
string.reverse( str )
Reverses every character in the string. Great for puzzles, secret codes, and fun effects.
local msg = "Hello World"
local secret = "desreveR"

print(string.reverse(msg))

-- Decode a secret message
print(string.reverse(secret))

-- Chain methods
print(string.upper(string.reverse(msg)))
Output
dlroW olleH
Reversed
DLROW OLLEH
EVERYTHING COMBINED

Operators + String Methods Together

A realistic example combining math operators, comparison operators, and string methods in one script

LUA — Combined example: Game Welcome System -- Player info
local playerName = "ali raza"
local score = 450
local level = 4
local lives = 3

-- String methods: clean up the name
local displayName = string.upper(playerName)
local nameLength = string.len(playerName)
local firstName = string.sub(playerName, 1, 3)

-- Math operators: calculate next level XP
local nextLevelXP = level ^ 2 * 100
local xpNeeded = nextLevelXP - score

-- Comparison operator
local isAlive = lives > 0

-- Print the welcome screen
print(string.rep("=", 24))
print("WELCOME, " .. displayName)
print("Name length: " .. nameLength)
print("Short name: " .. firstName)
print("Score: " .. score)
print("XP to next lvl: " .. xpNeeded)
print("Lives: " .. string.rep("❤️", lives))
print("Alive: " .. tostring(isAlive))
print(string.rep("=", 24))
Output

WELCOME, ALI RAZA
Name length: 8
Short name: ali
Score: 450
XP to next lvl: 1150
Lives: ❤️❤️❤️
Alive: true
========================
