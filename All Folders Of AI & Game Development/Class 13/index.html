What is a Function?

A function is a named block of code you can run whenever you need it — without retyping it every time.

Without a Function — Repeated Code
print("════════════")
print("WELCOME!")
print("════════════")

-- later in the script...
print("════════════")
print("WELCOME!")
print("════════════")
With a Function — Write Once
local function showWelcome()
  print("════════════")
  print("WELCOME!")
  print("════════════")
end

showWelcome()
-- later in the script...
showWelcome()

Function Syntax
local function functionName ( parameters )
-- code that runs when called
end

functionName(arguments) -- calls the function
LUA — A function with no input basic function
local function sayHello()
  print("Hello, Roblox!")
end

sayHello()
sayHello()
sayHello()
Output
Hello, Roblox!
Hello, Roblox!
Hello, Roblox!
Define vs Call
Writing local function sayHello() only defines it — it does NOT run yet. The function only runs when you write sayHello() with parentheses.
Parameters — Sending Information Into a Function

Parameters let a function behave differently each time it's called, based on what you send it.

LUA — Functions with parameters parameters
-- One parameter
local function greet(name)
  print("Hello, " .. name .. "!")
end

greet("Ahmed")
greet("Sara")

-- Two parameters
local function dealDamage(target, amount)
  print(target .. " took " .. amount .. " damage!")
end

dealDamage("Goblin", 25)
dealDamage("Dragon", 10)
Output
Hello, Ahmed!
Hello, Sara!
Goblin took 25 damage!
Dragon took 10 damage!
Parameter Order Matters
dealDamage("Goblin", 25) — the first value fills target, the second fills amount, in the exact order they were written in the function.
return — Sending a Result Back

A function can calculate something and hand the answer back using return. You can then store that answer in a variable.

LUA — Functions that return values return
-- Returns a calculated number
local function addNumbers(a, b)
  return a + b
end

local total = addNumbers(5, 3)
print("Total: " .. total)

-- Returns true or false
local function isAdult(age)
  if age >= 18 then
    return true
  else
    return false
  end
end

local result = isAdult(15)
print("Is adult: " .. tostring(result))
Output
Total: 8
Is adult: false
return vs print
print() only shows text in the Output window — the value is gone after. return sends the value back so it can be stored in a variable and used later in the script.
Functions + if/elseif/else

A function can contain conditions and return a different result depending on the input.

LUA — Rank function using elseif function + if/else
local function getRank(score)
  if score >= 90 then
    return "Gold"
  elseif score >= 70 then
    return "Silver"
  elseif score >= 50 then
    return "Bronze"
  else
    return "No Rank"
  end
end

print(getRank(95))
print(getRank(74))
print(getRank(30))
Output
Gold
Silver
No Rank
One Function, Many Results
The same getRank() function gives a different answer for every score sent into it — that's the entire point of parameters and return values working together.
Functions + Loops

Call a function repeatedly inside a loop — or use a loop inside a function.

LUA — Loop calling a function each time loop calls function
local function getRank(score)
  if score >= 90 then
    return "Gold"
  elseif score >= 70 then
    return "Silver"
  else
    return "Bronze"
  end
end

local scores = {95, 60, 82, 45}

for i = 1, #scores do
  local rank = getRank(scores[i])
  print("Player " .. i .. ": " .. rank)
end
Output
Player 1: Gold
Player 2: Bronze
Player 3: Silver
Player 4: Bronze
# scores — table length
#scores counts how many items are in the table. The loop runs once per item, no matter how many scores are added.
Functions + Parts — Reusable Part Builder

Write one function that creates a Part with chosen properties — call it as many times as needed with different values.

LUA — A function that builds a custom Part function + Instance.new
local function createBlock(xPos, color)
  local block = Instance.new("Part")
  block.Parent = workspace
  block.Size = Vector3.new(4, 4, 4)
  block.Anchored = true
  block.Position = Vector3.new(xPos, 2, 0)
  block.BrickColor = BrickColor.new(color)
  return block
end

-- Call it 3 times with different values
createBlock(0, "Bright red")
createBlock(6, "Bright blue")
createBlock(12, "Lime green")

print("3 blocks created!")
Output
3 blocks created!
Why This Is Powerful
Without the function, you would copy the same 6 lines 3 times. With the function, only one line changes per call — the position and color.
Combine With a Loop
Instead of calling createBlock() three separate times, you could use a for loop to call it 20 times — same function, way less code.
