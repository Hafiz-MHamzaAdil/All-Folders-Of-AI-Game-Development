⚔️
You are building a Roblox RPG (Role-Playing Game)
Every RPG game needs to track a player's stats — their name, health, level, gold coins, and whether they are alive. When the game starts, it sets up all these stats, prints a welcome screen, then simulates what happens during one round of the game: the player takes damage, earns coins, levels up, and their stats update in real time. You will write the script that does all of this — using only variables, data types, math operators, and print().
🎯 What This Task Covers
Declare all player stats as variables with the correct data types → print a welcome screen → simulate a game round by updating variables (take damage, earn coins, level up) → print updated stats after each event → print a final game-over screen. Every single value must come from a variable — no hardcoded numbers in the print lines.
Variables to Declare

Bonus Challenge ⭐
Add a Healing Potion Event
After Event 1 (taking damage), add a new event:

Event 1.5: Player drinks a healing potion and recovers 20 HP. But health cannot go above maxHealth!

Declare a variable:
local healAmount = 20

Add the heal to health:
health = health + healAmount

Print the result:
"🧪 Potion used! Health: " .. health

Then also try adding an armour variable (number) and subtract it from enemy damage before applying it to health.
