What is Game Development?

Making a game requires four disciplines working together — just like making a film needs a director, actors, music, and a script.

🎨
Discipline 1
Game Design
Planning the story, rules, levels, and characters. What does the player do? What are the goals?
💻
Discipline 2
Programming
Writing code — the game's brain. Everything that moves and reacts runs on code.
C++ · C# · Lua · Python
🖼️
Discipline 3
Art & Graphics
3D models, textures, animations. Everything the player sees is designed and created.
Blender · Photoshop
🎵
Discipline 4
Sound & Audio
Background music, sound effects, and voice acting that bring the world to life.
FMOD · Audacity
What is a Game Engine?

A game engine is a ready-made toolkit — physics, graphics, and input are already built in. You focus on building the game itself.

Without a Game Engine
Write physics from scratch, build your own renderer, handle every input manually — years of work before the game even starts.
With a Game Engine
Physics, graphics, input, audio — all built in. You jump straight into designing and building your game.

Setup — Account + Download Roblox Studio
  • 1
    Go to roblox.com → Sign Up
    Create a free account with a username, password, and birthdate. Write your username down — you will share games from this account.
  • 2
    Go to create.roblox.com → Download Roblox Studio
    Click "Start Creating". This downloads the Studio installer (~500MB). Start the download early if the internet is slow.
  • 3
    Run the installer → Sign in
    Double-click the downloaded file and install. When Studio opens, sign in with the Roblox account you just created.
  • 4
    Choose "Baseplate" template → Create
    From the Studio home screen select Baseplate. This gives a flat ground and sky — the perfect blank canvas to start building.
  • 5
    Studio opens — explore for 2 minutes before anything is explained
    Click around freely. Then the walkthrough begins.
Roblox Studio — 5 Core Panels

Find each panel on your screen as it is explained.

🌍
WORKSPACE
Your 3D world. Everything placed here appears in the game when you press Play.
📋
EXPLORER
A tree list of every object in the game. Shows parent-child hierarchy.
⚙️
PROPERTIES
Edit the selected object — color, size, position, material and more.
📦
TOOLBOX
Free library of 3D assets — trees, cars, buildings. Drag and drop to place.
💻
SCRIPT EDITOR
Where you write Lua code. Game logic and interactions live in scripts.
Top Toolbar — 3 Essential Tools
W
Move Tool
Select a Part and drag the colored arrows to move it along X, Y, or Z axis
R
Scale Tool
Drag the handles to make a Part bigger or smaller on any axis
E
Rotate Tool
Spin a Part around its center using the circular rotation handles
Camera:   Right-click drag = rotate  ·  Middle-click drag = pan  ·  Scroll = zoom
Parts — The Basic Building Block

A Part is any 3D object in Roblox. You build everything out of Parts — buildings, floors, walls, platforms, obstacles.

How to Add a Part
1. Click the Model tab in the top toolbar
2. Click Part — a block appears in Workspace
3. Or click the small arrow next to Part for other shapes:
   Block · Sphere · Cylinder · Wedge · Corner Wedge
Properties to Know
BrickColor — the color of the Part
Material — Wood, Metal, Glass, Neon, SmoothPlastic
Size — Width × Height × Depth
Anchored — true = stays in place, false = falls with gravity
Press F5 to Playtest
Press F5 to run the game and walk around inside your world.
Press F5 again (or click Stop) to exit playtest mode.

Important: Parts without Anchored = true will fall when Play is pressed. Always anchor your floors and walls.
Hands-On — 5 Challenges
  • 1
    Place 5 different Parts
    Model tab → Part. Place at least 5 Parts. Try Block, Sphere, Cylinder, and Wedge shapes.
  • 2
    Move, Scale, and Rotate each one
    Use W (move), R (scale), E (rotate). Make one very tall, one very wide, one tilted at an angle.
  • 3
    Change color and material
    Select a Part → Properties → BrickColor. Try different colors. Then change Material to Wood, Metal, Neon, and Glass.
  • 4
    Use the Toolbox
    Open Toolbox → search "house" or "tree" or "car" → drag into your world. Try at least 2 different assets.
  • 5
    Build a mini scene → Press Play
    Build anything — a house, a tower, a room. Press F5 to walk around inside your own 3D world. Remember to anchor your Parts!
