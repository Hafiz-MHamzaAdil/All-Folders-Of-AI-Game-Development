GUI — What's on the Screen

ScreenGui · TextLabel · Frame · TextButton · UDim2 · Live score on screen

What is GUI?

GUI is everything the player sees on screen that is NOT part of the 3D world — score, health bar, timer, buttons, menus. It sits on top of the game like a transparent overlay.

The Structure — StarterGui → ScreenGui → Elements

Everything must be in the right place. StarterGui is the Roblox folder that copies GUI to every player's screen.

📁 StarterGui ← Roblox built-in folder
📺 ScreenGui ← your canvas
🏷️ ScoreLabel ← TextLabel
🔲 HealthFrame ← Frame
🔲 HealthBar ← Frame inside Frame
🔘 ShopButton ← TextButton
Two ways to create GUI
Way 1 — Visual editor
Right-click StarterGui → Insert Object → ScreenGui → then add elements inside by right-clicking ScreenGui.

Way 2 — From code (LocalScript)
Use Instance.new() inside a LocalScript in StarterGui. This lets you update the GUI live during the game.
LUA — Create GUI from code LocalScript in StarterGui
-- LocalScript inside StarterGui
local player = game.Players.LocalPlayer
local playerGui = player.PlayerGui

-- Create the ScreenGui canvas
local screenGui = Instance.new("ScreenGui")
screenGui.Name = "GameHUD"
screenGui.Parent = playerGui

-- Create a TextLabel
local label = Instance.new("TextLabel")
label.Name = "ScoreLabel"
label.Parent = screenGui
label.Text = "Score: 0"
label.Size = UDim2.new(0.2, 0, 0.07, 0)
label.Position = UDim2.new(0.01, 0, 0.01, 0)
label.BackgroundColor3 = Color3.fromRGB(0, 0, 0)
label.BackgroundTransparency = 0.5
label.TextColor3 = Color3.fromRGB(255, 255, 255)
label.TextScaled = true
label.Font = Enum.Font.GothamBold
UDim2 — Position and Size on Screen

GUI does not use Vector3. It uses UDim2 — a system that mixes percentage of screen size and exact pixels.

UDim2.new(scaleX, offsetX, scaleY, offsetY)
Scale — percentage of screen (0.5 = 50%)
Offset — exact pixels added after scale
Top Left
(0,0, 0,0)
Top Centre
(0.5,0, 0,0)
Top Right
(1,0, 0,0)
Mid Left
(0,0, 0.5,0)
CENTRE
(0.5,0, 0.5,0)
Mid Right
(1,0, 0.5,0)
Bot Left
(0,0, 1,0)
Bot Centre
(0.5,0, 1,0)
Bot Right
(1,0, 1,0)
LUA — UDim2 examples position + size
-- Top left corner
label.Position = UDim2.new(0, 10, 0, 10)

-- Dead centre of screen
label.Position = UDim2.new(0.5, 0, 0.5, 0)
label.AnchorPoint = Vector2.new(0.5, 0.5)

-- Top right corner
label.Position = UDim2.new(1, -10, 0, 10)
label.AnchorPoint = Vector2.new(1, 0)

-- Half screen wide, 8% tall
label.Size = UDim2.new(0.5, 0, 0.08, 0)

-- 200px wide, 50px tall (fixed pixels)
label.Size = UDim2.new(0, 200, 0, 50)

Live Score on Screen — Updated in Real Time

The score label updates every time the player's Score stat changes. Put this in a LocalScript inside StarterGui.

LUA — Score label updates live LocalScript · StarterGui
-- LocalScript inside StarterGui
local Players = game:GetService("Players")
local player = Players.LocalPlayer
local playerGui = player.PlayerGui

-- Build the ScreenGui
local gui = Instance.new("ScreenGui")
gui.Name = "HUD"
gui.Parent = playerGui

-- Score label — top left
local scoreLabel = Instance.new("TextLabel")
scoreLabel.Name = "ScoreLabel"
scoreLabel.Parent = gui
scoreLabel.Size = UDim2.new(0.22, 0, 0.07, 0)
scoreLabel.Position = UDim2.new(0.01, 0, 0.02, 0)
scoreLabel.BackgroundColor3 = Color3.fromRGB(0, 0, 0)
scoreLabel.BackgroundTransparency = 0.4
scoreLabel.TextColor3 = Color3.fromRGB(255, 255, 255)
scoreLabel.TextScaled = true
scoreLabel.Font = Enum.Font.GothamBold
scoreLabel.Text = "🪙 Score: 0"

-- Wait for leaderstats to load
local ls = player:WaitForChild("leaderstats")
local score = ls:WaitForChild("Score")

-- Update label every time score changes
score.Changed:Connect(function(newVal)
  scoreLabel.Text = "🪙 Score: " .. newVal
end)
🪙 Score: 270
WaitForChild
The LocalScript runs the moment the player joins — before leaderstats is created by the server script. WaitForChild() pauses until the object exists. Always use it when reading leaderstats from a LocalScript.
LocalScript vs Script
GUI code must go in a LocalScript — not a Script. LocalScripts run on the player's device. Scripts run on the server. GUI is personal to each player, so it must be local.
Health Bar — Frame Inside Frame

A health bar is two Frames stacked — a grey background and a green fill. The fill's width changes as health changes.

LUA — Health bar that shrinks as HP drops health bar
-- Background bar (grey)
local bgBar = Instance.new("Frame")
bgBar.Parent = gui
bgBar.Size = UDim2.new(0.25, 0, 0.04, 0)
bgBar.Position = UDim2.new(0.01, 0, 0.1, 0)
bgBar.BackgroundColor3 = Color3.fromRGB(50, 50, 50)

-- Green fill bar
local fillBar = Instance.new("Frame")
fillBar.Parent = bgBar
fillBar.Size = UDim2.new(1, 0, 1, 0)
fillBar.BackgroundColor3 = Color3.fromRGB(34, 197, 94)

-- Update bar when health changes
local char = player.Character or player.CharacterAdded:Wait()
local hum = char:WaitForChild("Humanoid")

hum:GetPropertyChangedSignal("Health"):Connect(function()
  local pct = hum.Health / hum.MaxHealth
  fillBar.Size = UDim2.new(pct, 0, 1, 0)

  -- Change color at low health
  if pct < 0.3 then
    fillBar.BackgroundColor3 = Color3.fromRGB(220, 38, 38)
  else
    fillBar.BackgroundColor3 = Color3.fromRGB(34, 197, 94)
  end
end)
Health Bar States
Full Health (100%)
Half Health (50%)
Critical Health (20%) — turns red
How the bar shrinks
pct = health / maxHealth gives a number between 0 and 1. Setting the fill bar's X scale to pct makes it exactly as wide as the current health percentage.
