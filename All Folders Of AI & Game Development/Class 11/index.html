Loops — Repeat Without Rewriting

for loop · while loop · repeat until · Loops with Parts · Loops with if/else

What is a Loop?

A loop runs the same block of code multiple times — automatically. Instead of writing print("Step 1") print("Step 2") ten times, you write it once inside a loop.

Without a Loop — 5 lines of repeated code
print("Step 1")
print("Step 2")
print("Step 3")
print("Step 4")
print("Step 5")
With a Loop — same result, 3 lines
for i = 1, 5 do
  print("Step " .. i)
end
🔁
for
Repeat a set number of times
🔄
while
Repeat while a condition is true
🔃
repeat
Run once then keep going until condition
⛔
break
Stop a loop early
Output of the for loop above
Step 1
Step 2
Step 3
Step 4
Step 5
The for Loop

Use a for loop when you know exactly how many times to repeat.

for i = start , stop , step do
-- code runs each iteration
end
i = counter variable  ·  start = begin value  ·  stop = end value  ·  step = how much to increment (default is 1, can be omitted)
LUA — for loop basics for loop
-- Count from 1 to 5
for i = 1, 5 do
  print("Count: " .. i)
end

-- Count from 0 to 10 in steps of 2
for i = 0, 10, 2 do
  print("Even: " .. i)
end

-- Count DOWN from 5 to 1
for i = 5, 1, -1 do
  print("Countdown: " .. i)
end
print("🚀 Launch!")

for Loop — Using the Counter Variable

The counter i is a variable that changes every iteration. You can use it in calculations inside the loop.

LUA — i used in expressions counter variable
-- Multiplication table for 3
for i = 1, 10 do
  local result = 3 * i
  print("3 x " .. i .. " = " .. result)
end

-- Score increases each round
local score = 0
for round = 1, 5 do
  score = score + (round * 10)
  print("Round " .. round .. " | Score: " .. score)
end
Output
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
... up to 3 x 10 = 30
Round 1 | Score: 10
Round 2 | Score: 30
Round 3 | Score: 60
Round 4 | Score: 100
Round 5 | Score: 150
The while Loop

Use a while loop when you don't know exactly how many times to repeat — only a condition that decides when to stop.

while condition do
-- runs as long as condition is true
end
LUA — while loop basics while loop
-- Count up while less than 5
local count = 1
while count <= 5 do
  print("Count: " .. count)
  count = count + 1
end

-- Player lives — keep playing while alive
local lives = 3
while lives > 0 do
  print("❤️ Lives left: " .. lives)
  lives = lives - 1
end
print("💀 Game Over!")
Output
Count: 1
Count: 2
Count: 3
Count: 4
Count: 5
❤️ Lives left: 3
❤️ Lives left: 2
❤️ Lives left: 1
💀 Game Over!
⚠️ Infinite Loop — Avoid This
If the condition never becomes false, the loop runs forever and crashes the game. Always make sure the variable inside the condition changes inside the loop.
-- ❌ INFINITE LOOP — DO NOT RUN
local x = 1
while x > 0 do
  print("running...")
  -- x never changes — loops forever!
end
The repeat / until Loop

repeat always runs the code at least once — it checks the condition at the END, not the beginning. Stop when the condition becomes true.

repeat
-- always runs at least once
until condition
Stops when condition becomes true — opposite of while.
LUA — repeat until repeat
local attempts = 0

repeat
  attempts = attempts + 1
  print("Attempt: " .. attempts)
until attempts == 3

print("Done after " .. attempts .. " attempts")
Output
Attempt: 1
Attempt: 2
Attempt: 3
Done after 3 attempts
for vs while vs repeat
for — you know exactly how many times
while — repeat as long as something is true
repeat — always run once, then check
break — Stop a Loop Early

break immediately exits any loop — even if the condition is still true or the count hasn't finished.

LUA — break examples break
-- Stop when we find 7
for i = 1, 10 do
  if i == 7 then
    print("Found 7 — stopping!")
    break
  end
  print("i = " .. i)
end

-- Stop game loop when player dies
local health = 100
local round = 0
while true do
  round = round + 1
  health = health - 30
  print("Round " .. round .. " HP: " .. health)
  if health <= 0 then
    print("💀 Dead — game over!")
    break
  end
end
Output

i = 2
i = 3
i = 4
i = 5
i = 6
Found 7 — stopping!
Round 1 HP: 70
Round 2 HP: 40
Round 3 HP: 10
Round 4 HP: -20
💀 Dead — game over!
Loops + if/else Together

Combining loops with conditions is where real game logic is written.

LUA — Even and odd numbers loop + if
for i = 1, 10 do
  if i % 2 == 0 then
    print(i .. " is EVEN")
  else
    print(i .. " is ODD")
  end
end
LUA — Damage over multiple rounds loop + if
local health = 100
local damage = 25

for round = 1, 6 do
  health = health - damage

  if health > 50 then
    print("Round " .. round .. " 💚 HP: " .. health)
  elseif health > 0 then
    print("Round " .. round .. " 🔴 HP: " .. health)
  else
    print("Round " .. round .. " 💀 Dead!")
    break
  end
end

4 is EVEN
... and so on
Damage Output

Round 5 💀 Dead!
Loops + Parts — Spawn Multiple Parts with One Script

Instead of placing 10 Parts by hand in Studio, a loop can create and position them automatically.

Instance.new("Part") — Create a Part from code
Instance.new("Part") creates a brand new Part in the game — no need to place it manually in Studio.
You must set part.Parent = workspace to make it appear in the world.
LUA — Spawn 5 Parts in a row Instance.new
-- Creates 5 Parts spaced apart
for i = 1, 5 do

  local part = Instance.new("Part")
  part.Parent = workspace
  part.Size = Vector3.new(4, 1, 4)
  part.Anchored = true
  part.Position = Vector3.new(i * 5, 1, 0)

  print("Part " .. i .. " at X = " .. (i * 5))
end
LUA — Spawn 5 Parts with different colors color per part
local colors = {
  "Bright red",
  "Bright blue",
  "Lime green",
  "Bright yellow",
  "Hot pink"
}

for i = 1, 5 do
  local part = Instance.new("Part")
  part.Parent = workspace
  part.Size = Vector3.new(4, 4, 4)
  part.Anchored = true
  part.Position = Vector3.new(i * 6, 2, 0)
  part.BrickColor = BrickColor.new(colors[i])
  part.Material = Enum.Material.Neon
end
Output — 5 Parts spawned
Part 1 at X = 5
Part 2 at X = 10
Part 3 at X = 15
Part 4 at X = 20
Part 5 at X = 25
What students see in the 3D world
5 glowing neon Parts appear in a straight line — each a different color — spaced 6 studs apart. All created by the loop in one second. This is the moment students understand the real power of loops.
Tables { } — a quick note
{ "red", "blue", "green" } is a table — a list of values. colors[i] gets the item at position i. Tables are covered fully in a later class — for now just know that colors[1] = "Bright red", colors[2] = "Bright blue", etc.
Loops + if/else + Parts — All Together

Spawn 10 Parts. Even-numbered Parts are red, odd-numbered are blue. All decided by a condition inside the loop.

LUA — Checkerboard of Parts loop + if + Parts
for i = 1, 10 do

  local part = Instance.new("Part")
  part.Parent = workspace
  part.Size = Vector3.new(4, 1, 4)
  part.Anchored = true
  part.Position = Vector3.new(i * 5, 1, 0)

  -- Even = red, Odd = blue
  if i % 2 == 0 then
    part.BrickColor = BrickColor.new("Bright red")
    part.Material = Enum.Material.Neon
  else
    part.BrickColor = BrickColor.new("Bright blue")
    part.Material = Enum.Material.Neon
  end

  print("Part " .. i .. " placed")
end
Output
Part 1 placed
Part 2 placed
Part 3 placed
... up to Part 10
Result in the 3D World
10 neon Parts appear in a line — alternating red and blue — like a checkerboard track. 10 lines of code does the work of placing 10 Parts by hand AND setting all their colors.
