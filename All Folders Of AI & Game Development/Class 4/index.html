Variables + Parts

Use Lua variables to control the color, size, position and properties of 3D Parts in Roblox Studio.

Step 1 — Referencing a Part

Before you can change a Part, your script needs to know which Part to change. There are two ways.

Way 1 — Script is INSIDE the Part
Put the Script inside a Part in Explorer.
script.Parent refers to that Part automatically.

📁 Workspace
  📦 Part
    📄 Script ← here
Way 2 — Script is in ServerScriptService
Navigate to the Part by name.

📁 Workspace
  📦 MyCoolPart
📁 ServerScriptService
  📄 Script ← here
LUA — Both ways to reference a Part script.Parent
-- WAY 1: Script is inside the Part
local part = script.Parent
print(part.Name)

-- WAY 2: Script is in ServerScriptService
local part = workspace.MyCoolPart
print(part.Name)

-- Also valid:
local part = game.Workspace.MyCoolPart
print(part.Name)
Output — Part named "Block"

Changing Color — BrickColor
LUA — Color variable applied to Part BrickColor
-- Script is inside the Part
local part = script.Parent
local myColor = "Bright red"

part.BrickColor = BrickColor.new(myColor)
print("Color: " .. myColor)

-- Change color again using the same variable
myColor = "Lime green"
part.BrickColor = BrickColor.new(myColor)
print("Updated: " .. myColor)

-- Also try Material
part.Material = Enum.Material.Neon
Output
Color: Bright red
Updated: Lime green
BrickColor Names
"Bright red" "Bright blue" "Lime green" "Bright yellow" "Dark orange" "Hot pink" "Teal" "White" "Black" "Medium violet" "Cyan"

LUA — Size variables → Part Vector3
local part = script.Parent
local width = 10
local height = 1
local depth = 10

part.Size = Vector3.new(width, height, depth)
print("Size: " .. width .. "x" .. height .. "x" .. depth)

-- Double it using math operator
width = width * 2
height = height * 2
depth = depth * 2
part.Size = Vector3.new(width, height, depth)
print("Doubled: " .. width)
Output
Size: 10x1x10
Doubled: 20
Vector3.new( X, Y, Z )
Always three numbers in this order: width, height, depth. To make a flat floor use a small Y value like 1. To make a tall wall use a large Y value like 20.
Changing Position — Move a Part
LUA — Position variables → Part Position
local part = script.Parent
local posX = 0
local posY = 10 -- 10 studs up
local posZ = 0

part.Position = Vector3.new(posX, posY, posZ)
print("Y position: " .. posY)

-- Raise it 10 more units
posY = posY + 10
part.Position = Vector3.new(posX, posY, posZ)
print("Raised to: " .. posY)
Output
Y position: 10
Raised to: 20
Y = 0 is ground level
Y = 0 → ground level
Y = 10 → floating 10 studs above ground
Y = -5 → underground
Transparency · Anchored · Name
Transparency 0 to 1
local part = script.Parent
local alpha = 0.5

part.Transparency = alpha
print("Half transparent")

alpha = 1
part.Transparency = alpha
print("Invisible!")
Anchored Boolean
local part = script.Parent
local anchored = true

part.Anchored = anchored
print("Frozen in place")

anchored = false
part.Anchored = anchored
print("Now falling!")
Name String
local part = script.Parent
local newName = "SpawnPoint"

print("Before: " .. part.Name)

part.Name = newName

print("After: " .. part.Name)
Everything Together — One Full Setup Script
LUA — Full Part setup (Script inside Part) Complete
-- All values stored in variables at the top
local part = script.Parent
local partName = "HeroBlock"
local partColor = "Bright blue"
local partMaterial = Enum.Material.Neon
local width = 6
local height = 6
local depth = 6
local posX = 0
local posY = 10
local posZ = 0
local transparency = 0
local isAnchored = true

-- Apply everything to the Part
part.Name = partName
part.BrickColor = BrickColor.new(partColor)
part.Material = partMaterial
part.Size = Vector3.new(width, height, depth)
part.Position = Vector3.new(posX, posY, posZ)
part.Transparency = transparency
part.Anchored = isAnchored

print("Part ready: " .. part.Name)
print("Color: " .. partColor)
print("Size: " .. width .. "x" .. height .. "x" .. depth)
print("Y: " .. posY)
Output
Part ready: HeroBlock
Color: Bright blue
Size: 6x6x6
Y: 10
The Key Rule
All values are stored in variables at the top. To change anything — only edit the variable. The code below stays exactly the same.
