PART 1 · WHAT IS A CONDITION?

Every Game Makes Decisions

Every single thing that happens in a game is a decision — "if this, do that". Conditions are how code makes those decisions.

❤️
Game Decision 1
Health Check
If health reaches zero — then show Game Over screen
🏆
Game Decision 2
Win Condition
If score is above 100 — then the player wins the round
🚪
Game Decision 3
Door Lock
If player has a key — then open the door, else keep it locked
⭐
Game Decision 4
Rank System
If score is 90+ → Gold, elseif 70+ → Silver, else → Bronze
In Lua, all of these are written the same way
if condition then
-- code that runs if true
end
PART 1 · if / then / end

The Basic if Statement

The simplest form — check one condition. If it's true, run the code inside. If false, skip it entirely.

SYNTAX
if condition then
-- runs only if true
end
LUA — Basic if examplesif / then
local health = 80
local score = 120

-- Check 1: Is health low?
if health < 50 then
  print("⚠️ Warning! Low health!")
end

-- Check 2: Did player win?
if score > 100 then
  print("🏆 You won the round!")
end

-- Check 3: Is health full?
if health == 100 then
  print("💚 Full health!")
end
Output — health=80, score=120
🏆 You won the round!
Check 1 is skipped — 80 is NOT less than 50
Check 2 runs — 120 IS greater than 100
Check 3 is skipped — 80 is NOT equal to 100
Key Point
The code inside the if block only runs when the condition is true. If the condition is false, Lua skips straight to end and continues.
⚠️ Don't Forget end
Every if must close with end. Forgetting it is the most common error beginners make.
PART 2 · if / else / end

if / else — Two Outcomes

When you need one thing to happen if true, and a different thing if false — use else

SYNTAX
if condition then
-- runs if TRUE
else
-- runs if FALSE
end
LUA — if / else examplesif / else
local health = 30
local hasKey = true
local password= "roblox"

-- Are they alive?
if health > 0 then
  print("✅ Player is alive!")
else
  print("💀 Game Over!")
end

-- Do they have the key?
if hasKey == true then
  print("🚪 Door is OPEN!")
else
  print("🔒 Door is LOCKED!")
end

-- Is password correct?
if password == "roblox" then
  print("🔓 Access granted!")
else
  print("❌ Wrong password!")
end
Output
✅ Player is alive!
🚪 Door is OPEN!
🔓 Access granted!
HOW IT FLOWS
condition check
↓
true or false?
TRUE ↓
run if block
FALSE ↓
run else block
↓
end — continue
PART 3 · if / elseif / else

elseif — Multiple Outcomes

When there are more than two possible outcomes — add as many elseif branches as you need

SYNTAX
if condition1 then
-- condition1 is true
elseif condition2 then
-- condition2 is true
elseif condition3 then
-- condition3 is true
else
-- none of the above
end
LUA — Rank Systemelseif
local score = 74

if score >= 90 then
  print("🥇 Rank: GOLD")
elseif score >= 70 then
  print("🥈 Rank: SILVER")
elseif score >= 50 then
  print("🥉 Rank: BRONZE")
else
  print("❌ No Rank — Try Again")
end
Output — score = 74
🥈 Rank: SILVER
score >= 90? No. Skip.
score >= 70? Yes! Run this block. Stop checking.
Important — Lua stops at first match
Once Lua finds the first true condition, it runs that block and skips all the others — even if another condition would also be true. Order matters — always check from highest to lowest.
LUA — Level + Health Checkelseif
local level = 3

if level == 1 then
  print("👶 Beginner")
elseif level == 2 then
  print("🧑 Intermediate")
elseif level == 3 then
  print("💪 Advanced")
else
  print("🔥 MAX LEVEL!")
end
COMBINING CONDITIONS · and / or

and / or Inside Conditions

Combine multiple checks in one condition — use and when both must be true, or when either one is enough

LUA — and / or in conditionscombined
local health = 60
local hasArmour = true
local gold = 200
local level = 5

-- AND: both conditions must be true
if health > 50 and hasArmour == true then
  print("🛡️ Safe to fight!")
end

-- OR: at least one must be true
if gold >= 100 or level >= 5 then
  print("🏪 Shop unlocked!")
end

-- AND with else
if gold >= 500 and level >= 10 then
  print("⚔️ Legendary weapon unlocked!")
else
  print("🔒 Keep levelling up!")
end
Output
🛡️ Safe to fight!
🏪 Shop unlocked!
🔒 Keep levelling up!
and
Both must be true
T and T → true
T and F → false
F and T → false
F and F → false
or
At least one true
T or T → true
T or F → true
F or T → true
F or F → false
CONNECTING TO PARTS · if/else changes the 3D world

Make a Part React to a Condition

Now the if/else does something VISIBLE — the Part changes color based on the health value

LUA — Health bar color (Script inside Part)if + Part
local part = script.Parent
local health = 30 -- try: 100, 60, 30, 0

-- Change Part color based on health
if health >= 70 then
  part.BrickColor = BrickColor.new("Lime green")
  print("💚 Health OK: " .. health)
elseif health >= 40 then
  part.BrickColor = BrickColor.new("Bright yellow")
  print("🟡 Health Low: " .. health)
elseif health > 0 then
  part.BrickColor = BrickColor.new("Bright red")
  print("🔴 Critical! " .. health)
else
  part.BrickColor = BrickColor.new("Black")
  part.Transparency = 0.5
  print("💀 Dead!")
end
WHAT THE PART LOOKS LIKE
health ≥ 70 → Lime green — safe
health ≥ 40 → Yellow — warning
health > 0 → Red — critical
health = 0 → Black + transparent — dead
Try it live!
Change local health = 30 to 100, 60, 30, or 0 — press Play each time and watch the Part change color automatically.
🎮 SHORT GAME · Colour Guess Challenge

Mini Game — The Colour Trap

A 3-Part game — each Part is a different color. One is safe, one gives damage, one is deadly. The script decides what happens when you step on each one.

How to Build It
1. Add 3 Parts to Workspace — side by side
2. Name them SafePart, DamagePart, KillPart
3. Colour them Green, Yellow, Red manually
4. Add a Script inside each Part
5. Each script checks the player's health and reacts
Script for SafePart+20 HP
local part = script.Parent
local health = 60
local heal = 20

part.BrickColor = BrickColor.new("Lime green")
part.Anchored = true

if health < 100 then
  health = health + heal
  print("💚 Safe! Healed +" .. heal)
  print(" Health: " .. health)
else
  print("💚 Already full health!")
end
Script for DamagePart-30 HP
local part = script.Parent
local health = 60
local damage = 30

part.BrickColor = BrickColor.new("Bright yellow")
part.Anchored = true

health = health - damage
print("🟡 Ouch! -" .. damage .. " damage!")

if health <= 0 then
  print("💀 You died from damage!")
else
  print(" Health left: " .. health)
end
Script for KillPartINSTANT DEATH
local part = script.Parent
local health = 60
local isAlive = true

part.BrickColor = BrickColor.new("Bright red")
part.Material = Enum.Material.Neon
part.Anchored = true

health = 0
isAlive = false

print("🔴 DANGER ZONE!")

if isAlive == false then
  part.Transparency = 0.4
  print("💀 GAME OVER!")
  print(" Final health: " .. health)
end
Output when all 3 scripts run
💚 Safe! Healed +20
   Health: 80
🟡 Ouch! -30 damage!
   Health left: 30
🔴 DANGER ZONE!
💀 GAME OVER!
   Final health: 0
What students see
3 coloured Parts in the world. 3 different scripts. All using if/else. Each Part has a different behaviour — all controlled by conditions. This is exactly how real Roblox games work.
CLASS TASK · 25 MINUTES

Task — The Smart Checkpoint

Build a checkpoint Part that checks the player's score and gives a different reward depending on how well they did

The Scenario
The player reaches the end of a level and touches a glowing checkpoint. The checkpoint script checks their score, health, and whether they have a key — then decides what reward they get.
  • 1
    Add a Part — name it "Checkpoint"
    Make it tall and thin. Set Material to Neon. Anchor it. This is the end-of-level gate.
  • 2
    Insert a Script inside the Part
    Declare these variables: score (number), health (number), hasKey (boolean). Use your own values.
  • 3
    Write the Score Check — elseif
    If score ≥ 90 → print "⭐ PERFECT — Bonus chest unlocked!" and turn Part gold. elseif score ≥ 60 → "✅ PASSED" and turn green. else → "❌ FAILED" and turn red.
  • 4
    Write the Key Check — if / else
    If hasKey is true → print "🗝️ Secret door opened!". Else → print "🔒 No key — secret door stays locked."
  • 5
    Health Check bonus
    If health is 100 → print "💚 Perfect health bonus: +50 gold!" and add 50 to a gold variable. Else → print "❤️ Health: " .. health.
Example Output (score=75, hasKey=true, health=100)
✅ PASSED — Good job!
🗝️ Secret door opened!
💚 Perfect health bonus: +50 gold!
Example Output (score=40, hasKey=false, health=60)
❌ FAILED — Score too low!
🔒 No key — secret door stays locked.
❤️ Health: 60
Bonus ⭐
Add a lives variable. If lives == 0 AND score < 60 → print "💀 No lives left — GAME OVER!" and set part transparency to 0.8.

STUDENT GUIDE · HOW TO BUILD ANY GAME IDEA

3 Questions — Design Any Game

Before writing a single line of code, answer these three questions. Every game starts here.

❓
Question 1
What are the variables?
What information does the game need to track? Health? Score? Level? Coins? Write them all as variables first — before anything else.
local health = 100
local score = 0
local hasKey = false
🔀
Question 2
What are the conditions?
What decisions does the game make? "If score is high enough...", "If the player has the key...", "If health runs out...". These become your if/elseif/else blocks.
if health <= 0 then
  -- game over
end
✨
Question 3
What changes in the world?
What does the player see happen? Part color changes, transparency, size, position? This is where your Lua connects to the 3D world.
part.BrickColor =
  BrickColor.new("Red")
part.Transparency = 0.5
