Glass Bridge — Squid Game Style
5 rows of 2 glass panels. One panel in each row is safe (CanCollide = true — player can stand). The other is fake glass (CanCollide = false — player falls through). The script randomly picks which side is safe in each row using math.random() and if/else.

How It Works
Every row has 2 Parts — Left and Right.

The script uses math.random(1, 2) to pick which side is safe.

If safeSize == 1: Left panel → CanCollide = true, Right panel → CanCollide = false

Else (safeSize == 2): Right panel → CanCollide = true, Left panel → CanCollide = false

Safe glass looks bright and solid. Fake glass looks faded and transparent.
CanCollide — The Key Property
CanCollide = true → Player stands on it — solid glass
CanCollide = false → Player falls straight through it!

Glass Bridge — Full Game Script math.random · if/else · CanCollide · for loop
-- ══════════════════════════════════════
-- GLASS BRIDGE GAME — Squid Game Style
-- One safe panel per row, one fake
-- ══════════════════════════════════════

-- How many rows in the bridge
local totalRows = 5

print("🪟 Glass Bridge is being built...")
print(" " .. totalRows .. " rows · Choose wisely!")
print("════════════════════════════════")

-- Loop through every row
for row = 1, totalRows do

  -- Get the two panels for this row
  local leftPanel = workspace["Row" .. row .. "Left"]
  local rightPanel = workspace["Row" .. row .. "Right"]

  -- Set both to glass look
  leftPanel.Material = Enum.Material.Glass
  rightPanel.Material = Enum.Material.Glass
  leftPanel.Anchored = true
  rightPanel.Anchored = true

  -- Randomly pick which side is safe (1 = left, 2 = right)
  local safeSide = math.random(1, 2)

  -- Apply CanCollide and color based on the result
  if safeSide == 1 then

    -- Left is SAFE
    leftPanel.CanCollide = true
    leftPanel.BrickColor = BrickColor.new("Cyan")
    leftPanel.Transparency = 0.3

    -- Right is FAKE
    rightPanel.CanCollide = false
    rightPanel.BrickColor = BrickColor.new("Cyan")
    rightPanel.Transparency = 0.7

    print("Row " .. row .. " → LEFT is safe")

  else

    -- Right is SAFE
    rightPanel.CanCollide = true
    rightPanel.BrickColor = BrickColor.new("Cyan")
    rightPanel.Transparency = 0.3

    -- Left is FAKE
    leftPanel.CanCollide = true -- NOTE: still true so it renders
    leftPanel.CanCollide = false
    leftPanel.BrickColor = BrickColor.new("Cyan")
    leftPanel.Transparency = 0.7

    print("Row " .. row .. " → RIGHT is safe")

  end

end

print("════════════════════════════════")
print("✅ Bridge ready! Good luck...")
How to Build in Studio
  • 1
    Open Roblox Studio → Baseplate
    Raise the baseplate or add a platform high up — players need to fall when they step on fake glass.
  • 2
    Add 10 Parts — 2 per row, 5 rows
    Make them flat (e.g. Size 4, 0.5, 4). Place them side by side with a small gap between Left and Right panels.
  • 3
    Name them exactly
    Row1Left, Row1Right, Row2Left, Row2Right ... up to Row5. Names must match exactly — capital R, capital L or R at end.
  • 4
    Add Script to ServerScriptService
    Right-click ServerScriptService → Insert Object → Script. Paste the complete script. Press F5 to Play.
  • 5
    Walk across — step on wrong glass, you fall!
    Every time you press Play, math.random picks a new safe side. The answer changes every single game.

math.random() — What It Does
math.random(1, 2) randomly returns either 1 or 2 — like flipping a coin. Every time you press Play it picks again, so the bridge is different every round.
Code Breakdown — Line by Line
🔁
for loop
Repeats for every row
Instead of writing the same code 5 times, the for row = 1, totalRows loop runs the same logic for row 1, 2, 3, 4, 5 automatically.
🎲
math.random(1,2)
Randomly picks safe side
Returns 1 or 2 randomly — like rolling a dice. 1 = left is safe, 2 = right is safe. Different every Play — so the bridge changes every game.
✅
CanCollide = true
Safe glass — player stands
The safe panel is solid. Player walks on it normally. Transparency 0.3 — looks bright and clear.
💀
CanCollide = false
Fake glass — player falls
The fake panel has no collision. Player falls straight through it. Transparency 0.7 — looks slightly faded but still glassy.
🔀
if / else
Decides which side
If safeSide == 1 → left gets CanCollide true. Else → right gets CanCollide true. Every row gets its own random decision.
🪟
workspace[ ]
Find Part by name
workspace["Row1Left"] finds the Part named Row1Left. Using .. row .. builds the name dynamically inside the loop.
⭐ Make it Harder — Identical Glass
Make both panels look completely identical — same transparency, same color. Now the player truly cannot tell. Change both transparency values to 0.4 for safe and fake. Pure guessing game — just like the real Squid Game!
⭐ Add More Rows — Change 1 Line
Just change local totalRows = 5 to any number — 8, 10, 20. The loop handles the rest automatically. Add more Parts in Studio with the matching names and the script works with any number of rows.
