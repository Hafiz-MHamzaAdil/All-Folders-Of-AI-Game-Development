How Sound Works in Roblox

Sound in Roblox is an object — just like a Part. You insert a Sound object, give it a SoundId, and play it with code or have it play automatically.

🔊
Sound Object
The sound itself
Insert a Sound object inside a Part, in Workspace, or in SoundService for background music
🆔
SoundId
Which sound to play
Every Roblox audio has an ID number. Set SoundId to rbxassetid://NUMBER
▶️
Play / Stop
Control with code
Call sound:Play() to start and sound:Stop() to stop it at any time
🎵
Looped
Background music
Set Looped = true so the sound repeats forever — perfect for background music
Two Ways to Add a Sound
Way 1 — Insert manually in Studio
1. In Explorer, right-click a Part → Insert Object → Sound
2. Select the Sound in Explorer
3. In Properties find SoundId
4. Type: rbxassetid://9120386436
5. Tick Playing to auto-play on game start
6. Tick Looped for background music
Way 2 — Create from code
Use Instance.new("Sound") to create a Sound in Lua — full control over when it plays, volume, and looping. This is the better way when sound is triggered by events.
LUA — Create and play a sound from code Instance.new Sound
-- Create a sound object
local sound = Instance.new("Sound")
sound.Parent = workspace
sound.SoundId = "rbxassetid://9120386436"
sound.Volume = 0.5
sound.Looped = false

-- Play it
sound:Play()
print("🔊 Sound playing!")

-- Stop it
task.wait(3)
sound:Stop()
print("🔇 Sound stopped.")

Background Music — Plays the Whole Game

Put this in ServerScriptService. The music starts when the game loads and loops forever.

LUA — Background music Looped music

local music = Instance.new("Sound")
music.Parent = workspace

🎵 Music started!
SoundService — Better for music
For background music, set Parent = game:GetService("SoundService") instead of workspace. Music in SoundService plays at the same volume everywhere on the map regardless of where the player is.
Sound on Events — Play on Touch, Click, Damage

The most common use — trigger a sound effect when something happens in the game.

Coin pickup sound Touched
local part = script.Parent

-- Create the sound
local coinSound = Instance.new("Sound")
coinSound.Parent = part
coinSound.SoundId = "rbxassetid://4770482860"
coinSound.Volume = 1

part.Touched:Connect(function(hit)
  local hum = hit.Parent:FindFirstChild("Humanoid")
  if hum then
    coinSound:Play()
    print("🪙 ding!")
  end
end)
Damage / lava sound Touched
local part = script.Parent
local debounce = false

local dmgSound = Instance.new("Sound")
dmgSound.Parent = part
dmgSound.SoundId = "rbxassetid://1340851889"
dmgSound.Volume = 0.8

part.Touched:Connect(function(hit)
  if debounce then return end
  local hum = hit.Parent:FindFirstChild("Humanoid")
  if hum then
    debounce = true
    dmgSound:Play()
    hum.Health -= 25
    task.wait(1)
    debounce = false
  end
end)
Button click sound ClickDetector
local part = script.Parent
local detector = part:FindFirstChild("ClickDetector")

local clickSound = Instance.new("Sound")
clickSound.Parent = part
clickSound.SoundId = "rbxassetid://6042053626"
clickSound.Volume = 1

detector.MouseClick:Connect(function()
  clickSound:Play()
  part.BrickColor = BrickColor.new("Lime green")
  print("🔊 Click!")
end)
Add Sound to the Coin Collector Game

Take the coin collector from Class 9 and add three sounds — coin pickup, level up, and win. Just add these lines to the existing script.

LUA — Coin collector with sounds sounds added
local Players = game:GetService("Players")

-- Background music
local bgMusic = Instance.new("Sound")
bgMusic.Parent = workspace
bgMusic.SoundId = "rbxassetid://9120386436"
bgMusic.Volume = 0.3
bgMusic.Looped = true
bgMusic:Play()

-- Win sound
local winSound = Instance.new("Sound")
winSound.Parent = workspace
winSound.SoundId = "rbxassetid://4612355792"
winSound.Volume = 1

Players.PlayerAdded:Connect(function(player)
  local ls = Instance.new("Folder")
  ls.Name = "leaderstats" ; ls.Parent = player
  local coins = Instance.new("IntValue")
  coins.Name = "Coins" ; coins.Value = 0 ; coins.Parent = ls
  local level = Instance.new("IntValue")
  level.Name = "Level" ; level.Value = 1 ; level.Parent = ls
  local won = false

  coins.Changed:Connect(function(total)
    if total >= 60 then
      level.Value = 3
    elseif total >= 30 then
      level.Value = 2
    end
    if total >= 100 and not won then
      won = true
      winSound:Play() -- 🔊 WIN SOUND
      bgMusic:Stop() -- stop music on win
      print("🏆 " .. player.Name .. " WINS!")
    end
  end)
end)

-- Spawn 10 coins — each with a pickup sound
for i = 1, 10 do
  local coin = Instance.new("Part")
  coin.Shape = Enum.PartType.Ball
  coin.Size = Vector3.new(2,2,2)
  coin.BrickColor = BrickColor.new("Bright yellow")
  coin.Material = Enum.Material.Neon
  coin.Anchored = true
  coin.Position = Vector3.new(i*8,2,0)
  coin.Parent = workspace

  -- Coin pickup sound inside each coin
  local ding = Instance.new("Sound")
  ding.Parent = coin
  ding.SoundId = "rbxassetid://4770482860"
  ding.Volume = 1

  coin.Touched:Connect(function(hit)
    local plr = game.Players:GetPlayerFromCharacter(hit.Parent)
    if plr then
      ding:Play() -- 🔊 COIN SOUND
      plr.leaderstats.Coins.Value += 10
      coin:Destroy()
    end
  end)
end

Why play sound before Destroy()
The coin sound plays first, then the coin is destroyed. If you destroy the coin before playing the sound, the sound object gets deleted before it can make a noise.
Volume guide
Background music → 0.3 (quiet, ambient)
Coin / UI sounds → 0.8 – 1 (clear feedback)
Explosions → 0.6 – 0.8 (impactful, not harsh)
Using Your Own Sound File

You can upload any audio file from your computer to Roblox and use it in your game — background music, custom effects, your own recorded voice.

Supported File Formats
Roblox only accepts MP3 and OGG files.
Max file size: 20 MB

If your file is WAV, MP4, or another format — convert it first using a free tool:
online-audio-converter.com or Audacity
Where to get free music
Use royalty-free audio — not copyrighted songs:
🌐 freesound.org — free sound effects
🌐 pixabay.com/music — free background music
🌐 zapsplat.com — free SFX and music

Never upload YouTube audio — it will be removed by Roblox.
  • 1
    Go to create.roblox.com → sign in
    Open your browser and go to the Roblox Creator Dashboard.
  • 2
    Click "Development Items" → "Audio" → "Upload Asset"
    Find the Audio section in the left sidebar and click Upload Asset.
  • 3
    Choose your MP3 or OGG file → give it a name → Upload
    Roblox reviews it automatically. Short clips are approved instantly.
  • 4
    Copy the Asset ID from the URL
    After uploading, open the audio page. The URL looks like:
    create.roblox.com/store/asset/1234567890/my-sound
    That number is your Sound ID.
  • 5
    Paste the ID into your script
    Use the same code as any other sound — just replace the number with your own ID.
LUA — Using your own uploaded sound custom audio
-- Replace 1234567890 with YOUR asset ID
local mySound = Instance.new("Sound")
mySound.Parent = workspace
mySound.SoundId = "rbxassetid://1234567890"
mySound.Volume = 0.8
mySound.Looped = true

mySound:Play()
print("🎵 Custom music playing!")
That's it — same code
Everything works exactly the same as the built-in sounds. The only difference is the ID number. Once uploaded, your sound works just like any other Roblox audio.
⚠️ Copyright Warning
Never upload popular songs or copyrighted music. Roblox will automatically detect and remove it. Always use royalty-free audio or sounds you made yourself.
