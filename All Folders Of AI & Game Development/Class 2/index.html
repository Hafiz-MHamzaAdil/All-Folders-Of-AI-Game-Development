Build a Player Profile Card

One task that uses Variables, Data Types, and print() — all together

⏱ 25–30 minutes
👤 Individual
📘 Lua Scripting
Objective
🎯 What is this task?
Every game has a player with stats — a name, a level, health points, and a status. In this task, you will write a Lua script that stores a player's information in variables and then prints a full formatted profile to the Output window — just like a game's data system would do internally.

You will use all three data types (string, number, boolean), practice the .. operator, and see your output organized like a real game card.
The Scenario
🗺️
You are building a Roblox RPG game
When a player joins your game, the server needs to load their profile — name, level, health, coins, and whether they are currently online. Your script is the piece of code that sets up this profile and displays it. Right now it goes to the Output window. Later in the course, it will show on screen with a GUI.
Step-by-Step Instructions
1
Create the Script
In the Explorer panel, right-click ServerScriptService → Insert Object → Script. Double-click to open it. Delete the default line.
2
Declare your variables
Create 5 variables for the player profile. Use your own name and details — make it personal. Each variable must use the correct data type.
local playerName = "YourName"
3
Print a separator line
Before your profile, print a visual divider so the output looks clean and organized.
print("====================")
4
Print each profile field
Use print() with the .. operator to print each variable in a labeled line. Every line must use the variable — no hardcoded values.
print("Name: " .. playerName)
5
Update a variable and print the change
After printing the profile, change the coins variable (add 50 to it) and the isOnline variable (set it to false). Print both again to show the update. This proves variables can change — they are not fixed.
coins = coins + 50
isOnline = false
print("Updated coins: " .. coins)

Starter Code Structure — Shown After Students Try First
LUA — Player Profile Script (show only after students attempt on their own)
-- STEP 1: Declare all variables
local playerName = "Ahmed" -- String
local playerLevel = 5 -- Number
local playerHealth = 100 -- Number
local coins = 250 -- Number
local isOnline = true -- Boolean

-- STEP 2: Print the profile card
print("====================")
print("PLAYER PROFILE")
print("====================")
print("Name: " .. playerName)
print("Level: " .. playerLevel)
print("Health: " .. playerHealth)
print("Coins: " .. coins)
print("Online: " .. tostring(isOnline))

-- STEP 3: Update variables and print again
print("-- Updating profile...")
coins = coins + 50
isOnline = false
print("Updated Coins: " .. coins)
print("Online status: " .. tostring(isOnline))
print("====================")
